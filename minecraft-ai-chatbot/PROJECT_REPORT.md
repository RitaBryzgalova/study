## 📦 Созданные файлы

### Backend (Python)

```
backend/
├── src/
│   ├── main.py              (6.5 KB) - Flask приложение с 5 основными endpoints
│   ├── yandex_api.py        (4.5 KB) - Класс для работы с Яндекс API
│   ├── crafting.py          (4.3 KB) - Обработка данных о крафтах и модах
│   └── utils.py             (опционально)
├── requirements.txt         - Python зависимости (6 пакетов)
└── .env.example             - Шаблон конфигурации
```

**Основные компоненты:**
- `YandexAPI` класс для интеграции с API
- `CraftingDatabase` для работы с информацией о модах
- `CraftingHelper` для обработки запросов
- Flask приложение с REST endpoints

**Endpoints:**
- `GET /health` - проверка здоровья
- `GET /mods` - список поддерживаемых модов
- `POST /chat` - отправка запроса
- `POST /test` - тестирование
- Error handlers для всех ошибок

### Plugin (Java)

```
plugin/
├── src/main/java/com/minecraft/aichatbot/
│   └── AIChatBotPlugin.java   (8.4 KB) - Основной класс плагина
├── src/main/resources/
│   └── plugin.yml             - Конфигурация плагина
└── pom.xml                    - Maven конфигурация
```

**Основные методы:**
- `onEnable()` - инициализация плагина
- `onDisable()` - отключение плагина
- `onPlayerChat()` - обработчик событий чата
- `sendRequestToBackend()` - отправка запроса на сервер
- `checkBackendConnection()` - проверка подключения
- JSON парсинг и обработка

## 🚀 Как начать работу

### Минимум действий для запуска:

1. **Получить Яндекс API ключ**
   - Перейти на https://cloud.yandex.ru
   - Создать сервисный аккаунт
   - Создать API ключ

2. **Настроить backend**
   ```bash
   cd backend
   pip install -r requirements.txt
   cp .env.example .env
   # Отредактировать .env
   python src/main.py
   ```

3. **Скомпилировать плагин**
   ```bash
   cd plugin
   mvn clean package
   # Скопировать JAR на сервер
   ```

4. **Использовать в игре**
   ```
   !ai вопрос о крафте
   ```
